# 🦀 OpenClaw France — Kits d'installation gratuits

**OpenClaw** et **Hermes Agent**, installés proprement, en français, pour **0 €**.

Ce dépôt contient les kits distribués gratuitement sur **[openclaw-france.fr](https://openclaw-france.fr)** :

| Kit | Contenu | Dossier |
|---|---|---|
| 📦 **Kit OpenClaw** | Guide pas-à-pas, `docker-compose.yml`, `.env.example`, scripts (installation, sauvegarde, mise à jour), checklist sécurité | [`kit-openclaw/`](kit-openclaw/) |
| 🤖 **Kit Hermes Agent** | Guide complet FR, script d'installation macOS/Linux, `config-exemple.yaml`, premiers pas | [`kit-hermes/`](kit-hermes/) |

## Télécharger

- Site : **[openclaw-france.fr](https://openclaw-france.fr)** (zips + fichiers)
